# Security reporting

Please report suspected security issues privately by email to **support@fishandmedia.com** with **"Security"** in the subject line, before any public disclosure. Include the affected version, platform, reproduction steps, and impact. Do not include real passwords, recovery phrases, private keys, or NFC/QR records containing personal data.

We ask for a **90-day** coordinated-disclosure window from your first report, or until a fix ships if that is sooner. Do not send sensitive exploit details through public issue trackers.

The project does not currently publish a PGP key or a guaranteed response time. A response or fix is not guaranteed; this project has not had an independent security audit.
