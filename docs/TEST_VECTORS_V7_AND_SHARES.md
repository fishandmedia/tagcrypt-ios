# v7 and recovery-share deterministic vectors

These fixtures are interoperability examples, not production credentials. The v7 records are also embedded in `tests/test_tagcrypt_v7_recovery.py` and are decrypted by `tools/tagcrypt_v7_decrypt.py`.

## v7 passphrase envelope

Common inputs:

- Passphrase: `VECTOR_ONLY_passphrase_2026`
- KDF: Argon2id v1.3, time cost 2, memory cost 65,536 KiB, parallelism 1, 32-byte key
- JSON: `{"secret":"VECTOR_ONLY"}`
- Inner marker: `TC7\0`; padding flag `01`; JSON byte length is unsigned big-endian
- Padding bytes for the deterministic fixture: byte `i` is `(17*i + 3) mod 256`
- Salt: `00 01 02 03 04 05 06 07 08 09 0a 0b 0c 0d 0e 0f`
- Nonce: `00 01 02 03 04 05 06 07 08 09 0a 0b`
- Payload AAD: discriminator || salt

`DIRECT_BUCKET_VECTOR` has a 32-byte encrypted plaintext and an 81-byte envelope. `DIRECT_CAPACITY_VECTOR` has a 71-byte encrypted plaintext and a 119-byte envelope; 71 is deliberately not one of the QR buckets, covering capacity-dependent NFC padding. Both decrypt to the JSON above.

## Joint FIDO envelope emergency passphrase slot

`JOINT_FIDO_EMERGENCY_VECTOR` is a 291-byte v7 envelope with one Argon2id passphrase slot and one joint passphrase/FIDO slot. The test helper opens only the passphrase slot; it does not emulate a physical authenticator. The deterministic fixture values and full envelope are in the Python test file.

## Shamir arithmetic vector

For one input byte `s = 0x42` and polynomial coefficient `a = 0x07` over GF(2^8) with the AES polynomial `0x11b`, `y(x) = s XOR a*x`:

| x | Share value |
| ---: | ---: |
| 1 | `0x45` |
| 2 | `0x4c` |
| 3 | `0x4b` |

Combining any pair reconstructs `0x42`. One point alone is consistent with every possible secret byte and therefore provides no recovery information. App-generated shares additionally include the format marker, share index, original record length, random set identifier, and one share byte per encrypted-record byte.

## Scope

The Python tests exercise v7 passphrase recovery, arbitrary NFC padding length, joint-envelope emergency recovery, raw dump input, wrong-passphrase rejection, and payload tamper rejection. `tests/shares/main.swift` exercises every pair generated by the Swift implementation, binary-share round-trip, padded raw-page-share round-trip, and rejection of duplicate or mixed-set shares. Device behavior, corrupted-share handling through authenticated record decryption, and independent cryptographic review remain release gates.
